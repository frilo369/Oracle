Oracle's dashboard has been redesigned around the new gold-and-ruby visual reference.

- Gold chamfered frames, ruby glass controls, eclipse/portal artwork and Cinzel typography.
- Matching Overview and Settings screens, including the update check.
- Wider 1040×780 default window, with layouts checked down to 720×570 and in wide windows.
- Working match information, shortcut recording, guide selection and tray controls.

The existing startup updater and guide behaviour are retained. Layout, shortcut/update flows, performance and installer checks pass.

Install **Oracle-1.9-Setup.exe**, or let an installed Oracle 1.8 update at startup. You can also use **Settings → Check for updates**.
