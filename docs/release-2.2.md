Oracle 2.2 adds an experimental ARAM Mayhem augment overlay.

- Enable **Augment overlay · Beta** in Settings. It recognizes English augment names locally and shows champion-specific pick rates and reported tiers, with click-through labels that follow rerolls and hide after selection or when League loses focus.
- Use **Preview pick rates and tiers** to try the overlay without a match. The setting is off by default.
- Requires borderless fullscreen and Windows English text recognition. Live Mayhem card positioning and other display configurations still need in-game validation; genuine exclusive fullscreen is not supported.
- Keeps the corrected automatic updater and existing champion guides. Installer ZIP paths now work consistently under Windows PowerShell and PowerShell 7.

Native preview, OCR, layout, update, performance and automated checks passed. This is a beta feature; the preview does not establish that every League configuration works.
