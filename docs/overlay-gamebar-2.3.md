## Retained experiment

- `gamebar/OracleWidget.cpp` is a separate native C++/WinRT UWP companion using the Xbox Game Bar SDK. The owner enabled Developer Mode and manually pinned the widget and enabled click-through. Its registered development package is under `.test/gamebar-build-*`; do not delete that registered folder without replacing/unregistering the development package. Package family: `Frilo369.OracleWidget_9y1ac7xxt8800`.
- `scripts/build-gamebar.ps1 [-Register]` builds with MSVC, Windows SDK 10.0.26100.0 and pinned NuGet SDK 7.3.2607010. A monotonically increasing package revision is necessary: re-registering the same version at a new path retained the old package. No signed public widget distribution has been prepared.
- `overlay/gpu.rs` uses Windows Graphics Capture for the game monitor and crops to the eligible foreground game area. Per-window capture returned black for the owned exclusive fixture; Desktop Duplication returned stale/corrupt data. Monitor capture did return the correct owned exclusive frames. Live images/text are never saved; evidence is restricted to validated owned fixtures. Capture releases on loss of eligibility, with a worker timeout as a fallback.
- `overlay/controller.rs` separates recognition, statistics preparation and the renderer bridge. Active GPU scans are single-flight, at most 10 per second, and require two agreeing results. Labels expire, rerolls require renewed agreement, and selection/focus loss clears output. Inactive bridge writes are throttled. Host reactivation is bounded and only attempted in a real enabled match after pin/click-through setup has been acknowledged.
- Mayhem reuses the existing champion-specific Tencent guide. Arena uses the current MetaSRC guide model via host-only WebView2 evaluation, validates champion/mode/origin/path and never grants remote Tauri capabilities. Human verification remains manual and visible; no challenge bypass is implemented. Live Arena data preparation still needs acceptance.
- The OCR catalogue separates Arena/Mayhem IDs, conservatively tolerates unique small OCR errors, and rejects ambiguity. Bilinear sampling avoids degraded title strokes. Do not restore arbitrary word suffix candidates: malformed “Ultimate Recursion” previously became the different augment “Recursion”. Group spatially contiguous words before matching.
- The widget uses a real Page navigation after constructing the host, following Microsoft's bootstrap order. RequestedOpacity is a XAML 0..1 value in practice and in Microsoft's sample; dividing by 100 made labels nearly transparent despite prose documentation describing percentages. The local bounded bridge has timestamps and stale-output hiding. QA can request a render of the widget's own visual only; it contains no game pixels.
