Oracle now checks for updates automatically at startup. Settings includes a **Check for updates** button with clear progress and retry messages.

Updates download in the background, verify the installer's published SHA-256 digest and wait for League matches and shortcut recording to finish. Oracle then installs and restarts quietly. Preferences and extra files are preserved; a failed installation keeps the previous app and restarts it without an update retry loop.

Install **Oracle-1.8-Setup.exe** once to enable automatic updates from this version onward. Older versions cannot update themselves to 1.8. Portable copies report available versions and need the setup installed for automatic installation.

The compact dashboard and guide performance improvements from 1.7 are included.
